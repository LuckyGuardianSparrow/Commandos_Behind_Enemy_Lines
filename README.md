Multiplayer Game

To play the network game, the TCP/IP Protocol must be enabled in your system and your clients.
The recommended minimum system for the net game is as follows.

P166 with 32 MB RAM

The Commandos server CAN be placed behind a Firewall.  If you should have problems, see your MIS guru.

IPX protocol WAN or LAN support is NOT available in this game.

Modem or Serial Link support is NOT available in this game.

SETUP NOTES:

1. Faster gameplay can be achieved by starting a dedicated server (multiplayer server menu option).
   This means locating the fastest system, installing the game, starting the server, and then getting
   the IP Address and giving it to the clients. 
2. The Host NEEDS THE CD to HOST (Start) a game.  Clients DO NEED A FULL GAME INSTALLATION.
3. Generally if you and your clients live in a country with excellent phone lines or you and your 
   chums have a 56k+ connection, you can play the game with efficiency.  If you do not, play at 
   your own risk.
4. Latency increases with distance.

GAME NOTES:

1. If you lose a Commando, you will need to restart.
2. Pressing "Control+C and Z" activates the chat.
